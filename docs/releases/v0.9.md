# SwingCheck 0.9
Released October 27, 2026 · v0.9.0

Impact, confirmed by you.

## What's new

- **Impact is a marking step:** between Downswing and Follow-through, it opens on the frame SwingCheck found. Check it against the example, move it if it's off, and press Frame looks right. There's nothing to click.
- **One place to change marks:** the results page's Impact frame panel is gone. To change impact, use Edit marks.
- **Impact examples:** Rory McIlroy at impact, or Tiger Woods with a driver.
