# SwingCheck 0.2
Released October 5, 2026 · v0.2.0 to v0.2.9

Cleaner addresses, a darker look, link previews, a place in the queue, and a numbers-only page for running the site.

## What's new

- **Clean addresses:** pages have real links (/new, /swing/…, /terms, /privacy), so Back and Forward work as expected.
- **Dark mode by default,** with a Light mode switch in the footer.
- **Link previews:** sharing swingcheck.org in Messenger, Facebook, Viber, or WhatsApp shows a picture card.
- **Your place in line:** a waiting swing shows how many are ahead of it and a rough wait.
- **Admin page:** live status, 7-day counts, uploaders per day, wait and analysis times, and activity by hour. Numbers only: never anyone's swings, names, or addresses.

## Fixes and tweaks

- **v0.2.1:** "Nothing fancy, just geometry" and the shorter tagline "Film it. Check it. Fix what matters."
- **v0.2.2:** a long press to aim on an iPhone no longer selects text or opens the image menu.
- **v0.2.4:** a smaller link-preview picture, so phones that build previews themselves show it.
- **v0.2.5:** releases wait for uploads in progress, not only for analyses.
- **v0.2.7 to v0.2.9:** the admin page's layout, and "See example" and "Back to marking" on phones.
